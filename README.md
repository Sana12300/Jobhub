
# JobHub – Job Portal

A job portal built using Python and Django that helps job seekers find and apply for jobs.

## Features
- User registration and login
- Browse jobs and view job details
- Apply for jobs and upload resumes
- View submitted applications
- Recruiter dashboard to post, edit, and delete jobs

## Technologies
- Python
- Django
- HTML
- CSS
- SQLite

## Run Project
python manage.py migrate
python manage.py runserver
